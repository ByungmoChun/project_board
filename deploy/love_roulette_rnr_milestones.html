배경 — 자사 연애 리얼리티 영상 IP 「러브룰렛」(OTT·TV 방송용 제작물)의 촬영본을 활용해, 플레이어가 모니터룸에서 출연자들을 지켜보고 선택하는 Steam FMV 게임으로 만든다. 엔진은 유니티(9/17 결정 — Maker 대비 제작 속도 우위). 퀵게임 게임팩토리 전략의 자체 제작 1호 성격이며, 게임 완성도만큼 "어떻게 발견되게 할 것인가"가 성패를 가르는 장르라 유입 전략(3장)을 제작 마일스톤과 같은 문서에서 관리한다.

3. Steam FMV 유입 전략 — 채널 정리

원칙: Steam 자체가 주 채널이고, 바깥 채널은 전부 Steam 스토어 페이지로 사람을 보내 위시리스트를 쌓는 역할이다. 행사(Next Fest)는 이미 가진 관심을 증폭할 뿐 처음부터 만들어 주지 않는다.

3.1 권장 실행 순서

스토어 페이지 오픈(M6) → 숏폼·원작 채널로 위시리스트 누적 → 데모 공개(M7) → 크리에이터 배포(M8, UTM 측정) → 출시(M9). Next Fest는 영상 소스 확정 후 참가 여부 판단(마일스톤 외)

3.2 주의할 점

  • 벤치마크의 한계: 「Love Is All Around」의 판매는 대부분 중국 시장에서 나왔다. 국내·일본 시장에서 같은 규모를 기대하기보다 "크리에이터가 방송하고 싶은 게임"이라는 성공 구조를 가져오는 것이 핵심.
  • 성인 이용가: 기획서상 1차 타깃은 Steam 유료 단품·성인 이용가. 성인 콘텐츠 설정은 스토어 노출·Next Fest 노출·크리에이터 방송 가능 여부에 직접 영향을 주므로, 등급 설정과 방송용 가이드를 M6 전에 확정.
  • 자막·현지화: 한국어 원본이라 해외 유입은 자막 품질이 곧 입구. 최소 영어, 가능하면 일본어·중국어.
  • 영상 소스 일정 미정: 수령일이 정해지지 않은 상태라 출시일은 M4 확정 후에만 역산 가능. 그전까지는 M3·M6을 최대한 진척시켜 둔다.
  • 안국주 팀장 부하: 10월 초 신데렐라 백업 온보딩(10/01~10/07)·네이버 레드 Maker 지원(~10/02)과 겹친다. M3 시작일은 이 둘이 끝난 뒤로 잡는 것을 권장.
  • M4 공백 활용: 수령일이 미정인 동안 M3 구조 개발과 스토어 페이지 준비(M6)를 먼저 진행해, 영상이 도착하는 즉시 편집만 남는 상태를 만든다.
  • 출연자 초상권·방송 계약: 촬영본의 게임 사용과 출연진 홍보 참여가 계약 범위에 있는지 M4 수령 전에 확인.

4. 운영 규칙

  • 주간 체크: 목요일 저녁 보드 갱신 시 마일스톤 진행과 위시리스트 수(M6 이후)를 함께 반영, 금요일 주간회의에서 확인.
  • 날짜 변경: 담당 제안 → 총괄 승인 → 표 갱신. 구두 변경 금지.
